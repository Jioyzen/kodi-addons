# Floating home navigation

Outline icons: Lucide Static 0.468.0 (ISC license, LUCIDE-LICENSE.txt), https://lucide.dev/. SVG sources retained; white PNG exports are 192×192 and display at 64×64 in Kodi.

Focus and accent are antialiased rounded flat masks, generated at 4× resolution. Focus: 264×196, radius 28. Accent: 84×6, radius 3; color follows `button_focus`. Only the active home list shows the focus treatment. Normal and selected icon/text coordinates are identical; no zoom or fade animation. Existing menu actions and visibility settings are retained.
