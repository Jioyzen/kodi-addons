# 应用页卡片

独立皮肤窗口 `1120` 使用 Kodi 已启用程序入口（`addons://sources/executable/`），每行五张、每屏三行，卡片 328 × 185。名称位于下方，主题色边框只标记当前焦点。聚焦时卡片和边框在 130ms 内放大至 110%，名称保持稳定；失焦直接恢复正常布局，不执行回缩动画。放大后仍位于当前网格单元内，列表不循环。

现有应用采用边缘延展图：原始图标保持在中央，向上下左右复制最近边界像素，离原图越远越柔化。原图内部保持清晰，边界处柔化权重为零，不使用一个平均颜色拼接，避免方形接缝。透明图标先合成到中性或品牌底色再延展。

开发工具 `scripts/build_application_cards.py` 从本地图标构建 `cards/`，使用 Pillow，不在盒子页面打开时运行，不请求网络。manifest 记录原始图标哈希。图标更新时重新生成对应卡片；新安装应用默认使用原始图标和中性背景，不影响入口自动发现。

card.svg、outline.svg 为代码绘制的几何资源，PNG 为抗锯齿渲染文件。卡片半径 20，选中轮廓宽度 4，轮廓容器在卡片四周外扩 3px，内边缘留在图片外侧。背景直接使用皮肤壁纸／图案层，不叠加应用提供的 fanart，不跟随程序焦点变化。无新增运行时插件、服务或依赖。
