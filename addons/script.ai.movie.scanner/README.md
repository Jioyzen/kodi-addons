# AI 刮削入库：电视剧匹配

版本 1.9.8 为电视剧增加独立的目录与季集匹配流程。电影继续使用原来的身份核验和长片筛选流程。

## 使用方法

AI 兜底解析默认接口为 `https://api.deepseek.com`，模型为 `deepseek-flash`，均可编辑或清空。API 密钥默认留空，填写后在插件设置中明文显示；关闭“启用 AI 兜底解析”时，接口、密钥和模型仍显示，但不可编辑，已有配置继续保留。

添加目录时可选择 **自动识别、电影、电视剧**。电视剧建议每部剧放在独立目录，目录中保留剧名和年份；分季时使用 `Season 01`、`S01`、`第一季` 等子目录。

支持的示例：

```text
电视剧/西游记.1986/01 猴王初问世.mkv
电视剧/示例剧.2020/Season 02/03.mkv
电视剧/示例剧.2020/S01E01.mkv
电视剧/示例剧.2020/S01E01-E04.mkv
电视剧/示例剧.2020/第十二集.mkv
电视剧/示例剧.2020/Specials/S00E01.mkv
```

单集名称只用于本地集标题提示，不作为剧名检索。普通电影目录中的编号电影不会仅因 `01` 前缀就被当作电视剧。旧目录继续按自动识别处理。

手动匹配优先提取剧目录的名称和年份，检索电视剧候选。在剧目录上手动确认剧名后，统一处理目录内的单集和附加内容；整部剧确认后，无法对应官方季集的内容归入该剧末尾的“未知集”。目录信息不足时可以输入剧名或 TMDb ID。

## 数据与准确性

- 同名候选必须结合年份核验。后续季可以使用该季首播年份，无法可靠区分时保留人工确认。
- 以整季为单位获取单集资料，并在一次扫描内共享剧级身份与季资料，避免每个文件重复请求。
- 不为本地内容伪造 TMDb 单集身份。剧目录确认后，编号缺失、越界、官方列表缺少对应集的文件以原文件名作为本地“未知集”收录；临时网络失败仍保留重试状态，避免覆盖已有的准确资料。
- 多集合并文件为每一集建立记录，所有记录指向同一个真实文件。它不是自动切割视频，也不生成集间播放时间标记。
- 只有源编号完整覆盖一整季、且能唯一核实偏移量时，才将续集的连续编号换算为该季集号；不完整的越界编号作为未知集保留。
- 明确标注的精编/剪辑版保留本地编号，不借用原版不同剪辑的单集剧情、首播日期或单集 ID。
- `Bonus`、番外、花絮、访谈、删减片段等附加内容保留在所属剧的末尾“未知集”中；嵌套的附加内容目录向上归属剧目录，官方 Specials 仍支持第 0 季匹配。
- 未知集保留原文件名，按数字自然顺序排序；重新扫描仍保持自然顺序，已有文件的关联和观看状态保留。它们不借用其他正式单集的剧情、首播日期或 ID。
- 国产剧等多剧目录先展示剧目录与匹配统计；进入剧目录后查看单集。大列表每页最多 80 项。
- 所有插件菜单使用 Kodi 官方支持的离屏 ListItem 创建方式，完成后整批交给界面显示，避免构建列表时反复等待界面锁。
- 媒体源菜单、进度只展示目录名和协议，如 `国产剧[SMB]`；剧列表及剧内导航标题只显示剧名和年份，不附带协议。插件链接使用不含认证信息的路径标识，真实连接信息仅供后台使用。
- 同一单集的不同编码文件各自保留，不会覆盖另一文件的关联。Kodi 原生列表可能显示两条单集记录。
- 写入按文件进行事务提交，合并集要么全部完成、要么全部回滚。共享电影写锁，保留已有文件的添加时间、观看次数和续播书签。
- 剧级 ID 去重，单集保存真实 TMDb ID、评分、演员和剧照；图片缓存使用与数据库一致的图片尺寸。

## 开发验证

```sh
python3 scripts/test_tv_scanner.py
python3 scripts/test_tv_directory.py
python3 scripts/test_movie_scanner.py
```

测试使用脱敏路径、模拟网络响应和 Kodi 22 数据库表结构，不包含媒体文件、用户数据库或密钥。

“扫描媒体库文件”检查所有已添加目录的新增/删除文件；目录长按菜单中的同名入口仅检查当前目录。它们保留已匹配结果，新文件进入待匹配列表，识别刮削使用“扫描全部／扫描此目录”入口。停止扫描只在扫描或文件检查进行中显示；文件检查收到停止请求后完成当前目录，再停止后续目录。

文件列表中点击影片或单集会直接播放所选文件，未匹配的视频也可播放。电影条目保留“手动匹配”，电视剧在剧目录上统一匹配，单集无需手动匹配；保留 Kodi 的“添加收藏”，禁用列表条目的“由此连续播放”等自动排队入口。导航链接仍使用不含认证信息的路径标识，只有播放器解析阶段才读取真实地址。

目录级手动匹配会保存确认的剧身份，后续新发现的单集继承它；其他剧目录和电影的匹配结果保持独立。直接添加的单剧目录，也可在插件首页该目录的长按菜单中匹配。
