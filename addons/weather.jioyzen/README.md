# 天气卡片 0.5.3

提供中国天气网城市／区县天气与 Embuary Mod（Jioyzen）桌面卡片，无需账户或 API 密钥，尚未发布到仓库。

## 位置设置

默认“自动获取位置”：国内出口 IP → IP9 城市定位（支持 GBK 的环境可回退太平洋网络）→ 中国天气网搜索，核对省市、唯一匹配站点 → 实时天气与预报。IP 定位仅作市级证据，不当作设备 GPS；同名地点、城市和同名县不自动混用。

启用并保存自动获取时清除手动站点、已选位置文字和旧版省市配置；再次关闭后需重新搜索选择位置。自动模式下不显示手动位置文字。

关闭自动获取后使用“搜索并选择位置”，输入中文、拼音首字母或全拼（例如米东／md／midong），核对地区后确认。保存站点编号与名称，并在只读的“已选位置”显示结果；重新打开设置会从保存的站点恢复该文字。后续直接请求该站点，不再查询 IP 或搜索名称。搜索取消、失败或没有结果不覆盖原来的配置；多个同名结果由用户选择。搜索结果排除景点、街道等不支持此实时数据端点的站点。

兼容旧版省市和坐标配置，刷新时按省份与名称解析中国天气网站点。不携带用户地点、密钥或设备地址，不记录或缓存公网 IP。

## 天气数据

- 直接 HTTPS 读取中国天气网网页的数据端点（weather.com.cn），无需注册和积分。它们是网站内部接口，并非承诺长期不变的公共 API；若接口改变需更新插件。
- 严格解析 JSON/JSONP 包装，不执行服务端 JavaScript；校验站点编号、日期、温度范围和响应大小，拒绝错误页面及 999 等占位温度。
- 提供温度、天气现象、湿度、实时风向/风级、当天高低温。体感温度、降水概率缺少可靠字段，清空属性并隐藏，不把降水量或未说明字段当作概率。
- 预报按明确日期选今天，不依赖可能滞后的“今天”标签；跨年按发布时间解析。仅返回有效的未来七天，预报故障时保留可用的实时天气。
- 常规刷新复用 30 分钟缓存。网络失败时保留并标记最近成功天气；磁盘缓存写入故障不覆盖新的实时结果。切换数据提供方会绕过旧提供方的有效期缓存。
- Kodi 每次刷新会清空天气窗口属性。桌面通过 Home 窗口独立快照展示，刷新期间卡片保持显示；无后台常驻服务、皮肤定时器或逐帧 Python 调用。
- 仅依赖 Kodi Python 与 Python 标准库，无 CEBOX 依赖。`RunScript(weather.jioyzen,probe)` 只更新插件数据文件，不切换页面。
- 皮肤仅在插件启用、被选为天气提供者且有可用数据时绘制卡片；插件未安装时皮肤正常工作。
- 图标资源来自 https://www.tianqi.com/wulumuqi/，来源在 resources/icons/sources.json。中国天气网条件代码与 Kodi 图标分别处理，缺少本地图标时使用 Kodi 图标。

配置入口同时注册为程序插件，打开“天气卡片”即可配置。现阶段扩展预报属性使用摄氏单位。

开发时热部署新增翻译文件后，需要切换语言再切回当前语言以重新加载插件文字；UpdateLocalAddons 与 ReloadSkin 不重新加载全部插件翻译。正常安装或重启 Kodi 会加载翻译文件。

皮肤首次启用可调用 RunScript(weather.jioyzen,activate_if_unset)，仅在系统没有天气提供者时自动选择本插件并刷新，不打开设置页面、不覆盖其他天气提供者。
