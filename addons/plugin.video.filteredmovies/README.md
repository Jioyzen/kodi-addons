# 海报墙

版本 2.4.2 增加独立的电视剧详情与季选集页面。首页、全部影片、电视剧分类和搜索中的电视剧海报都进入同一套页面，信息键也使用它；电影信息页在 2.5.0 中改为插件独立页面。

剧集详情以媒体背景图、标题标识、年份/类型、简介和圆角季海报为主。无标题标识时显示剧名，无季海报时使用剧海报。只展示 Kodi 中已有单集的季，保留特别篇和“未知集”等自定义季名。

季页面采用左侧海报、右侧简介、下方横版单集卡片的布局，支持缩略图横排和纯集数按钮展示。优先读取本地纹理缓存；无单集剧照时使用剧集背景图，不提取片源视频截图。每次最多读取 80 条单集，“加载更多单集”继续读取下一批，列表两端不循环。

播放按钮优先跟随最近观看记录：有续播点时继续该集，已看完时选择下一集；从未播放时选择未观看单集，并沿用原生续播；点击单集播放该集。收藏使用 Kodi 收藏，观看状态由 Kodi 原生媒体库接口写入，整剧/整季操作需在界面确认。不修改媒体文件，不重新刮削。

返回键从季页面回到剧集详情并保留季焦点，再返回海报墙并恢复原页面位置。数据异步读取，返回或关闭会废弃过期结果；页面不保留跨窗口的原生 ListItem。加载失败、无季或无单集都有明确提示。

季页面下方增加圆形演职人员头像与角色名，优先使用当前季已入库单集的演员资料。点击头像进入独立演员页，先展示本地参演作品，再按需加载 TMDb 人物简介；通过来源剧集和头像核验人物身份，同名不明确时保留本地信息。参演作品仅按演员查询本地 Kodi 媒体库，有多少展示多少，不请求在线作品列表；没有本地作品时隐藏此板块。人物请求有超时与限量缓存，不阻塞季页面加载。

单集卡片下方以一个连续文本块展示标题与简介，最多三行，超出内容用省略号收尾。按钮使用固定文字区域与同步加载的本地资源，不依赖估算字体宽度；本季演员头像批量查找缓存，并复用同一 TMDb 头像已缓存的其他尺寸。


2.4.4 完善分类筛选：补齐惊悚、奇幻、家庭、西部、纪录片等电影类型，以及动作冒险、科幻与奇幻、战争与政治等电视剧类型；只显示当前分类实际拥有的选项。类型名称的简体、繁体与英文别名统一处理；组合类型按组成部分筛选。类型选项较多时可在同一行向右浏览。自定义未知类型仍由“其他”筛选覆盖。电视剧国家／地区读取当前 Kodi 数据库字段。

2.4.5：类型按钮统一使用两个中文字，25 种常用类型在电影和电视剧分类中始终显示；暂无资源的类型仍可选择并显示明确的空结果提示。“其他”只在存在未知类型时显示。动作冒险同时纳入动作和冒险；科幻与奇幻同时纳入科幻和奇幻；战争与政治同时纳入战争和政治。原始数据库标签保持完整。

2.4.7：记住最后手动选择的排序方式和升降序，全部影片、电影、电视剧等分类共用该选择；返回首页、重新打开海报墙或重启 Kodi 后仍保留。首次使用默认添加日期降序。排序偏好与临时类型、地区等筛选独立存储在插件用户数据中。

2.4.8：全部影片、电影、电视剧、系列合集、演唱会、纪录片各自保存排序方式和升降序，互不覆盖。首次进入尚未设置排序的分类时使用添加日期降序。


2.5.0：电影海报及信息键进入独立电影详情页，使用全屏媒体背景、标题标识、影片资料、简介、续播进度、圆角播放按钮、收藏与观看状态按钮，以及圆形演职人员。复用剧集页面的缓存头像和本地演员作品页；返回时保留来源分类、焦点和位置。首页“继续观看”的普通点击仍直接播放。

详情页只读取 Kodi 已入库的元数据与本地图片缓存，不遍历或探测媒体共享。字幕与音轨沿用播放器的选择功能。未确实提供 Atmos 信息时不会显示 Atmos 标识。


2.5.1：电影详情页移除字幕／音轨选择、简介展开及屏幕返回按钮；遥控返回键保持有效。播放按钮只使用一个固定文字层，不通过 Python 重设底层按钮文字和字体，初始加载状态与最终播放／续播状态统一呈现。演职人员上移到操作按钮下方，不再需要聚焦后整页移动。进度条使用独立的 10px 圆端纹理及固定端帽，避免将大尺寸胶囊图片挤压成尖端。

电影页手动切换已观看／未观看时，同一次原生 Kodi API 调用会清除续播书签；刷新后显示“播放”，下次从头开始。保存完成前暂时禁用播放按钮，避免用旧进度发起播放。不会改写片源文件，也不会批量清除其他影片的进度。


2.5.2：大分类首次打开仅绑定第一批海报。第二批仍在后台预读，但只保留最多 120 项原始元数据，接近已加载列表末尾时再追加，避免 Kodi 全量重绑列表而重播焦点缩放动画。已处于默认海报焦点时不重复设置焦点；排序／筛选刷新和关闭会丢弃旧预读结果，预读失败不影响当前已显示页面。


2.5.3：详情／季页面及播放结束返回分类时，只要查询条件一致且原列表仍在，就保留分类、滚动位置和所选海报。续播、观看次数导致的媒体库更新不再清空列表；异步回到同一海报，只更新它的播放进度及观看状态，不重新绑定整页。返回恢复只执行一次，即使 Kodi 的 onInit 回调晚于子页面关闭也不触发重载。返回海报直接保持焦点放大尺寸，继续导航时仍使用原来的动画。后台预读随媒体库变化失效；分页被子页面打断后可正常重试。


2.5.4：从分类／详情／播放返回首页时，立即复用已显示的推荐，不将整个首页重置为加载状态。媒体库变化时后台核对每行推荐：顺序不变的卡片原位更新进度、观看状态、图片和元数据；成员变化时只重绑对应一行，并按媒体身份保留当前选中项。未完成加载的板块在后台补齐，临时更新失败保留旧内容。首页返回恢复只执行一次，避免延迟回调覆盖已经更新的焦点。


2.5.5：继续观看仅读取 Kodi 本地媒体库中未完成的电影和单集续播书签，不再汇总整部电视剧或电影合集，不依赖“历史记录”插件。按最近播放时间混排，最多 30 项，不循环。单集显示剧名、季集号和单集标题，优先用已缓存剧照／剧背景图；点击按原生单集 ID 续播，信息键打开所属季页面。更新专用缓存标识，避免沿用旧的合集推荐；不修改媒体库的合集关系或观看记录。


2.5.6：收藏为空时 Kodi 可能返回 `favourites: null`；统一将空值、缺失字段及不合法列表归一为无收藏状态，覆盖电影、电视剧详情与通用收藏入口。收藏读取不再中断详情绑定、续播进度和播放按钮启用。播放仅使用 Kodi 原生电影／单集 ID 和媒体库书签，不依赖“历史记录”插件。


2.5.7：首页分类按钮改为即时焦点高亮，移除缩放与淡入淡出过渡，并取消这一行的滚动动画，避免快速导航时高亮拖尾和粘连。保留圆角卡片、主题色及原有入口与导航规则。


2.5.8：电影、电视剧和季详情首帧先读取本地媒体库的轻量续播／单集目标，不再让播放按钮等待简介、演职人员及纹理缓存处理。电影直接显示播放或继续播放；剧集按最近播放进度及当前季显示目标集数。查询只读、有超时和数量上限；数据库暂时不可用时仍由原异步加载器恢复，不猜测播放目标、不展示加载占位文字。剧集播放按钮仅保留单个文字层，避免原生 setLabel 引起字体和底层文字重绘。


2.5.9：分类页的新方向键输入优先于未完成的返回焦点恢复；原生焦点已经移动时不恢复旧位置，续播状态仍按媒体身份异步更新。延迟的左右行边缘回调在当前焦点不再位于边缘时丢弃，避免对新焦点重复移动。返回现存分类控件时保留筛选导航布局，尺寸未变化不重复设置海报面板几何；减少原生控制消息和布局重算。保留原有不循环、跨行、返回首屏和播放后保留位置的规则。


2.5.10：稳定性审查修复。首页首次加载与增量更新统一通过活动窗口的 GUI 回调绑定，返回时重建控件采用直接绑定，避免后台线程操作原生列表或等待自身回调。电影首轮信息绑定完成前的播放通知合并为一次后续刷新，不再提前释放加载状态并废弃首轮结果。剧集与演员页在子窗口／播放器活动时保留结果，返回后再应用。相同演员列表及本地参演作品原位更新，不因续播或人物简介返回而重建卡片；已缓存头像不启动重复重试线程。

图片与查询缓存增加线程同步、明确容量上限，缓存读写错误不破坏现有图片；磁盘缓存校验结构，初始化失败及时关闭连接。全部影片混合分页的元数据补齐也只取默认电影版本，防止错误引用其他版本或额外内容。演员本地作品分页支持取消与重复页检测，人物联网请求限制并发；空季、空单集和空演员数据正常处理。读媒体库和图片缓存保持只读，不探测媒体共享文件，不改变页面布局或用户设置。


2.5.11：详情页面返回时检查原生容器内容和 Python 列表是否都仍存在，复用已加载的季、单集、演员及本地作品列表，保留横向浏览位置；原生控件重建时重新绑定，避免沿用未显示的旧列表。播放返回焦点只应用一次，返回整剧时清理季页面的播放焦点记录；已有正确焦点不重复设置，新方向键输入优先于延迟的详情返回状态。电影／剧集监听器忽略结构异常的更新通知。
